#### Add DecayingAverage to resource manager

- Using suffix for time as suggested previously
- We keep `window` around so that we can write `decay_rate`
  Q: is this necessary?
  - If we wanted to change the decay rate that we use in our average,
    then we'd need the original window to re-calculate our decay rate.
  - This seems pretty unlikely; and if we did want to change the
    decay rate formula, we could probably just write a new field?
- Q: should we update `value_at_timestamp` to be non-mut?
  - This could give us issues where we progress the timestamp forward
    without writing the value, use that value and then later add a
    value to the decayed value that's _before_ the timestamp that we
    queried; we wouldn't fail but the queried value would actually be
    stale.

#### Add RevenueAverage to ResourceManager

- We want to track multiple windows average to prevent shocks to our
  values.
- Q: does `windows_tracked` have validation elsewhere that the ts is >
  than the start time?
  - Yes, checked at callsite
- Matt's comment about `AggregateWindowAverage`:
  - Kind of understand what this means: we're tracking one long average,
    and then dividing by window count which means that the amount that
    we decay will be exaggerated by the division and the decay.
  - Claude suggests a different decay that will not "double penalize"
    our older values that are already decayed by the average.

+	/// Returns the average value per window using a decay-weighted divisor that accounts for
+	/// the reduced contribution of older data due to decay, avoiding the double-penalty of
+	/// dividing by the raw window count.
+	///
+	/// The effective number of windows is: ∫₀ᵀ r^t dt / W = (1 - r^T) / (-W · ln(r))
+	/// where r is the per-second decay rate, T is elapsed seconds, and W is window duration.
+	fn value_at_timestamp_corrected(&mut self, timestamp_unix_secs: u64) -> Result<i64, ()> {
+		if timestamp_unix_secs < self.start_timestamp_unix_secs {
+			return Err(());
+		}
+
+		let decayed_sum = self.aggregated_revenue_decaying.value_at_timestamp(timestamp_unix_secs)?
+			as f64;
+		let elapsed_secs =
+			(timestamp_unix_secs - self.start_timestamp_unix_secs) as f64;
+
+		if elapsed_secs == 0.0 {
+			return Ok(decayed_sum.round() as i64);
+		}
+
+		let r = self.aggregated_revenue_decaying.decay_rate;
+		let w = self.window_duration.as_secs_f64();
+
+		// Effective windows = (1 - r^T) / (-W * ln(r)), capped at window_count.
+		let effective_windows = ((1.0 - r.powf(elapsed_secs)) / (-w * r.ln()))
+			.min(self.window_count as f64)
+			.max(1.0);
+
+		Ok((decayed_sum / effective_windows).round() as i64)
+	}
